Le suivi de vol prévient quelqu'un de vos décollages et de vos arrivées. Il existe deux suivis distincts : par SMS, vers une personne de votre choix, et dans PilotDuty Manager, pour votre organisation.

Les deux se règlent dans l'onglet des réglages, à la ligne du suivi de vol. Une pastille sur cette ligne indique l'état de la couverture.

## Suivi par SMS

Avec PilotDuty+ ou PilotDuty Pro.

Votre suiveur reçoit des SMS aux moments clés du vol. Il n'a pas besoin de l'app.

### Configurer le suiveur

1. Entrez le nom et le numéro de téléphone du suiveur, au format international.
2. Demandez-lui son accord, puis touchez « J'ai son accord ». Cette attestation est demandée pour chaque nouveau numéro. Rien n'est coché d'avance.
3. Choisissez les messages à envoyer : décollage, atterrissage, retard.
4. Activez le suivi. L'app vous demande l'autorisation d'envoyer des notifications.

Après votre attestation, le suiveur reçoit un message de bienvenue.

### Les messages

Selon vos choix, le suiveur peut recevoir :

- un message au décollage ;
- un message à l'atterrissage ;
- une confirmation d'arrivée ;
- une alerte de retard si votre arrivée n'est pas confirmée.

Le serveur PilotDuty rédige et envoie les messages, pas votre téléphone. L'iPhone a donc besoin du réseau pour les déclencher.

### Si le suiveur répond STOP

Un suiveur qui répond STOP ne reçoit plus de messages. Vous ne pouvez pas réactiver le suivi vers ce numéro tant qu'il n'a pas répondu START.

### La pastille de couverture

- Rouge : personne ne recevra vos messages.
- Orange : la couverture n'est pas vérifiée.

Un bandeau du tableau de bord peut aussi vous signaler un problème de couverture. Touchez-le pour ouvrir les réglages du suivi.

## Confirmer votre arrivée « safe »

Après l'atterrissage, un vol suivi attend votre confirmation d'arrivée dans le tableau de bord. Glissez-le vers la gauche pour le confirmer « safe ». Vous pouvez aussi le confirmer depuis l'écran de l'événement, en glissant le vol vers la gauche.

Un vol lié au suivi ne peut pas être supprimé de son événement.

## Suivi dans PilotDuty Manager

Pour les membres d'une organisation abonnée à PilotDuty Manager.

Activez « Suivi de vol sur PilotDuty Manager ». Sans organisation abonnée, ce réglage est désactivé.

- Au décollage, l'app crée le suivi du vol et y ajoute des jalons : position, altitude et cap.
- Votre organisation suit le vol dans le Manager : feuille de vol, carte et alertes de retard.
- Le suivi est visible du Manager avant même que vous approuviez le vol.
- Le vol est marqué arrivé quand vous le confirmez « safe ». Au décollage suivant, l'app confirme aussi le vol précédent.

Le suivi dans le Manager ne dépend pas du suivi par SMS. Vous pouvez activer l'un, l'autre ou les deux.

## Bon à savoir

Le suivi commence au décollage détecté. Si l'enregistrement automatique ne fonctionne pas, le suivi non plus. Voir [Enregistrement automatique](/fr/docs/app/enregistrement-automatique).
