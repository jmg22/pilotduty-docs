L'écran de santé pilote rassemble vos documents aéronautiques : certificats médicaux, licences et compétences. Pour chacun, il affiche les jours qui restent avant l'échéance.

Avec PilotDuty Pro.

## Ouvrir l'écran

Touchez le bouclier en haut à gauche du tableau de bord. Il affiche le nombre de jours restants du document le plus proche de son échéance, dans la couleur de son statut.

- Sans PilotDuty Pro, le bouton est verrouillé et présente l'abonnement.
- Si des mémos de votre organisation attendent votre attention, le bouton affiche une enveloppe à la place. Voir [Avec votre organisation](/fr/docs/app/avec-votre-organisation).

## Ajouter un document

1. Touchez « + ».
2. Choisissez un médical, une licence ou une compétence.
3. Choisissez l'autorité : Transports Canada, FAA, EASA ou une autre autorité.
4. Remplissez la fiche. Chaque changement est enregistré tout de suite.

Pour supprimer un document, glissez-le vers la gauche.

## Certificat médical

- Choisissez la catégorie ou la classe proposée par l'autorité : catégorie 1 ou 3, classe 1 à 3, ou LAPL.
- Entrez votre date de naissance et la date de votre dernier examen. L'app calcule la validité selon les règles de l'autorité choisie.
- Pour une autre autorité, entrez vous-même la date de fin de validité.
- Ajoutez les coordonnées de votre médecin. Vous pouvez ensuite l'appeler, ou ouvrir son adresse dans Plans, depuis la fiche.
- Joignez au besoin une photo du certificat.

La réduction de validité de la classe 1 EASA après 60 ans n'est pas prise en compte. Vérifiez cette date vous-même.

## Licences

Une fiche de licence comprend :

- le type : licence ou permis d'élève-pilote ;
- le code et le numéro ;
- les dates ;
- les catégories avion et hélicoptère ;
- la qualification de classe ;
- les annotations, à activer une à une ;
- des notes et une photo.

## Compétences

Les compétences couvrent les contrôles et les qualifications périodiques : PPC, IPC, PCC, vol de contrôle, qualification, annotation, compétence linguistique (ELP), cours, formation périodique, ou compétence personnalisée.

Les champs s'adaptent au type choisi : avion, code de qualification ou d'annotation, licence associée, niveau de compétence linguistique (4, 5 ou 6), examinateur, résultat, sujet, remarques et photo. La validité est préréglée selon le code choisi.

## Jours restants et couleurs

- Vert : le document est valide.
- Jaune : l'échéance approche. Pour un médical, le jaune apparaît 30 jours avant ; pour une licence, 90 jours avant.
- Rouge : la date est dépassée.

Le bouclier du tableau de bord reprend le statut le moins favorable de l'ensemble de vos documents. Ouvrez l'écran de santé pilote régulièrement pour garder vos dates à l'œil.

## Fiches délivrées par votre organisation

Si votre organisation vous a délivré une licence, une annotation ou une compétence dans PilotDuty Manager, la fiche apparaît dans l'app en lecture seule. Vous ne pouvez ni la modifier ni la supprimer.

Vos fiches sont les mêmes dans l'app et dans le Manager : si vous êtes membre d'une organisation, son personnel les voit sur votre fiche pilote.
