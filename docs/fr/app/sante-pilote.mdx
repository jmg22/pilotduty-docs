L'écran de santé pilote (« Pilot Status ») rassemble vos documents aéronautiques : certificats médicaux, licences et compétences. Pour que PilotDuty calcule la validité de votre médical, de votre licence et de vos contrôles de compétence, entrez vos données personnelles. L'écran affiche ensuite, pour chaque document, les jours qui restent avant l'échéance.

Avec PilotDuty Pro.

Les captures de cette page datent de 2025. Depuis, vous pouvez enregistrer plusieurs documents de chaque type, chacun avec son autorité : l'écran actuel peut donc différer un peu.

## Étape 1 : ouvrir l'écran de santé pilote

1. Ouvrez le tableau de bord.
2. Touchez le badge de validité (le bouclier) en haut à gauche.
3. L'écran « Pilot Status » s'ouvre.

Le badge affiche le nombre de jours restants du document le plus proche de son échéance, dans la couleur de son statut.

- Sans PilotDuty Pro, le bouton est verrouillé et présente l'abonnement.
- Si des mémos de votre organisation attendent votre attention, le bouton affiche une enveloppe à la place. Voir [Avec votre organisation](/fr/docs/app/avec-votre-organisation).

## Étape 2 : entrer votre certificat médical

1. Touchez « + », choisissez un médical, puis l'autorité : Transports Canada, FAA, EASA ou une autre autorité.
2. Choisissez la catégorie ou la classe proposée par l'autorité : catégorie 1 ou 3, classe 1 à 3, ou LAPL.
3. Entrez votre date de naissance et la date de votre dernier examen médical (« Last Medical Date »). L'app calcule la validité selon les règles de l'autorité choisie. Pour une autre autorité, entrez vous-même la date de fin de validité.
4. Facultatif : ajoutez le nom, le numéro de téléphone et l'adresse de votre médecin. Une fois ces informations remplies, un bouton d'appel et un bouton de navigation apparaissent : vous pouvez appeler votre médecin, ou ouvrir son adresse dans Plans, depuis la fiche.
5. Facultatif : ajoutez une photo de votre certificat médical.

La réduction de validité de la classe 1 EASA après 60 ans n'est pas prise en compte. Vérifiez cette date vous-même.

![La fiche du médical : date de naissance, date du dernier examen, coordonnées du médecin avec les boutons d'appel et de navigation, et photo du certificat (floutées)](/docs-media/app/pilot-health-medical.png)

## Étape 3 : entrer votre licence

1. Touchez « + », choisissez une licence, puis l'autorité.
2. Touchez la case de date et choisissez les dates de votre licence, dont sa date d'expiration.
3. Facultatif : ajoutez une photo de votre licence.

Une fiche de licence comprend aussi :

- le type : licence ou permis d'élève-pilote ;
- le code et le numéro ;
- les catégories avion et hélicoptère ;
- la qualification de classe ;
- les annotations, à activer une à une ;
- des notes.

![La fiche de licence : date d'expiration de la licence et photo du document (floutée)](/docs-media/app/pilot-health-license.png)

## Étape 4 : entrer vos contrôles de compétence

Les compétences couvrent les contrôles et les qualifications périodiques : PPC, IPC, PCC, vol de contrôle, qualification, annotation, compétence linguistique (ELP), cours, formation périodique, ou compétence personnalisée.

1. Touchez « + », choisissez une compétence, puis l'autorité.
2. Entrez, par exemple pour un contrôle de compétence :
   - la date de début de validité ;
   - le type d'avion, par exemple C172 ;
   - le type de contrôle, par exemple PCC ou PPC ;
   - la durée de validité, en mois, par exemple 12. Elle est préréglée selon le code choisi ;
   - facultatif : le nom de l'examinateur et des remarques.

Les champs s'adaptent au type choisi : avion, code de qualification ou d'annotation, licence associée, niveau de compétence linguistique (4, 5 ou 6), examinateur, résultat, sujet, remarques et photo.

![La fiche d'un contrôle de compétence : début de validité, type d'avion C172, type de contrôle, durée de validité de 12 mois, examinateur et remarques](/docs-media/app/pilot-health-proficiency-check.png)

## Modifier ou supprimer un document

Chaque changement est enregistré tout de suite : il n'y a pas de bouton d'enregistrement. Pour supprimer un document, glissez-le vers la gauche.

## Jours restants et couleurs

Une fois les informations enregistrées, PilotDuty calcule d'office le nombre de jours qui restent avant l'échéance de chaque document.

- Vert : le document est valide.
- Jaune : l'échéance approche. Pour un médical, le jaune apparaît 30 jours avant ; pour une licence, 90 jours avant.
- Rouge : la date est dépassée.

Le bouclier du tableau de bord reprend le statut le moins favorable de l'ensemble de vos documents, en vert, jaune ou rouge. Ouvrez l'écran de santé pilote régulièrement pour garder vos dates à l'œil.

## Fiches délivrées par votre organisation

Si votre organisation vous a délivré une licence, une annotation ou une compétence dans PilotDuty Manager, la fiche apparaît dans l'app en lecture seule. Vous ne pouvez ni la modifier ni la supprimer.

Vos fiches sont les mêmes dans l'app et dans le Manager : si vous êtes membre d'une organisation, son personnel les voit sur votre fiche pilote.
