L'app iPhone PilotDuty et le Manager utilisent le même compte et la même base. Ce que le pilote fait dans l'app remonte dans le Manager, sans export ni import.

## Même compte, même base

Le pilote se connecte à l'app avec le compte qu'il utilise dans le Manager. Il peut aussi se servir de l'app seul, sans organisation. Pour bien démarrer avec l'app, voyez le [guide de l'app](/fr/docs/app/premiers-pas).

## Les vols approuvés remontent

Un vol enregistré par l'app reste sur l'iPhone tant que le pilote ne l'a pas approuvé. Une fois approuvé, il apparaît dans son carnet, sous sa fiche dans le Manager. Il met à jour tout seul ses totaux, ainsi que les heures et cycles de l'aéronef de l'organisation. Une correction faite dans le Manager arrive en direct dans l'app. Voir [Pilotes et temps de service](/fr/docs/manager/pilotes-et-temps-de-service).

## Le suivi de vol

Dans l'app, le pilote active le réglage « Suivi de vol sur PilotDuty Manager ». Ce réglage n'est offert qu'à un membre d'une organisation abonnée.

Après le décollage, le vol apparaît sur la Feuille de vol et sur la carte, avec ses jalons : position, altitude et cap. Il se rattache seul à la réservation confirmée de l'aéronef, et l'équipage d'un même vol est regroupé. Le pilote peut confirmer son arrivée depuis son iPhone. Voir [Suivi de vol](/fr/docs/manager/suivi-de-vol).

## Fiches aéronefs et défectuosités

- Pour utiliser un aéronef de l'organisation dans l'app, le pilote l'importe (« Avion », « + », « Avion d'organisation »).
- Dans l'app, il consulte la fiche de l'aéronef : caractéristiques, heures, cycles, prochaine inspection et défectuosités actives.
- Un membre de rôle Pilote et plus signale une défectuosité depuis l'app. Elle arrive dans l'onglet « Défectuosités » de l'aéronef, dans le Manager : voir [Flotte et maintenance](/fr/docs/manager/flotte-et-maintenance).

La gestion des aéronefs et de la maintenance reste dans le Manager : l'app consulte et signale.

## Mémos

Les mémos publiés dans le Manager arrivent dans la boîte de mémos de l'app, avec une notification si l'auteur l'a choisie. Le pilote les lit, ouvre les pièces jointes et confirme « Lu et compris » ; vous suivez les confirmations dans le Manager. Un lien de mémo s'ouvre directement dans l'app. Cette fonction ne demande aucun abonnement personnel. Voir [Mémos](/fr/docs/manager/memos).

## Médical, compétences et horaire de compagnie

Le médical, les licences et les compétences que le pilote tient dans l'app (abonnement personnel PilotDuty Pro) s'affichent sur sa fiche pilote dans le Manager. Une source d'horaire de compagnie ajoutée dans l'app apparaît dans le Manager, et inversement (Pro). Voir [Agendas](/fr/docs/manager/agendas).

## L'organisation abonnée lève la limite de vols

L'app gratuite est limitée à 3 vols par mois. Un pilote membre d'une organisation abonnée n'a plus cette limite. L'abonnement de l'organisation ne donne pas pour autant PilotDuty+ ni PilotDuty Pro : voir [Abonnement](/fr/docs/manager/abonnement).

## Ce que l'app ne fait pas

- L'app n'a aucune fonction de réservation. Pour voir ses réservations sur iPhone, le membre ajoute son lien « Synchroniser mon agenda » à son agenda : voir [Agendas](/fr/docs/manager/agendas).
- La Feuille de vol, la facturation, la formation, la rédaction des mémos et la gestion de la flotte se font dans le Manager.
- Le temps de service selon la réglementation se calcule dans l'app (abonnement personnel PilotDuty Pro). Le Manager n'en affiche que des repères.

## À savoir

- Un vol que le pilote n'a pas approuvé n'existe pas pour le Manager, sauf son suivi de vol.
- Un vol ne compte aux heures d'un aéronef que si son pilote est membre de l'organisation de l'aéronef.
- L'écran de fin de création d'un aéronef le rappelle : une modification faite plus tard à sa configuration n'est pas reprise sur les iPhone qui l'ont déjà importé.
