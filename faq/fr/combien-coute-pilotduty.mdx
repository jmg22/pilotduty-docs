L'app iPhone est gratuite jusqu'à 3 vols par mois ; PilotDuty+ et PilotDuty Pro s'achètent dans l'app. PilotDuty Manager est gratuit pour une organisation d'un seul membre ; au-delà, l'organisation choisit Growth ou Unlimited.

Tous les prix, en dollars américains, sont sur la page [Tarifs](/fr/tarifs).
