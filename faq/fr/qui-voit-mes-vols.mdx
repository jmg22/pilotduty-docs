---
question: "Qui voit mes vols si je suis membre d'une organisation ?"
category: account
order: 1
translationKey: faq-privacy-org
updated: 2026-11-01
draft: false
---

Vos vols restent dans l'app tant que vous ne les approuvez pas. Une fois approuvés, ils sont dans votre carnet, que le personnel autorisé de votre organisation (rôle Instructeur et plus) peut consulter dans le Manager, y compris les vols faits ailleurs.

Le suivi de vol vers le Manager est un réglage que vous activez dans l'app.
