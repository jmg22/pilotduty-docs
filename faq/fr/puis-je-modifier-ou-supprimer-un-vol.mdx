---
question: "Puis-je modifier ou supprimer un vol ?"
category: app
order: 7
translationKey: faq-edit-flight
updated: 2026-11-01
draft: false
---

Oui. Avant l'approbation, touchez le vol dans le tableau de bord pour corriger ses heures, ses aérodromes, l'avion ou ses remarques. Glissez-le vers la droite pour le supprimer.

Après l'approbation, désapprouvez-le depuis le carnet en indiquant la raison : il revient dans la file d'approbation, où vous le corrigez avant de l'approuver de nouveau. Chaque changement crée une version, que vous retrouvez dans l'historique du vol.

Vous pouvez aussi corriger vos vols dans PilotDuty Manager : l'app reçoit ces changements. Le personnel de votre organisation peut consulter votre carnet, mais pas le modifier. Voir [Relecture et approbation](/fr/docs/app/relecture-et-approbation).
